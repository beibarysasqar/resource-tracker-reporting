# Onboarding checklist

For a new member of the resource planning team. The buddy and the team lead go through it together with the newcomer. Tick a step only when it is really done.

Owner codes: TL = team lead, B = buddy, N = newcomer.

## Before the first day

- [ ] 1. Create the Microsoft 365 account and add it to the team group (TL)
- [ ] 2. Give access to the SharePoint library "Resource Planning" and the Planner board (TL)
- [ ] 3. Assign a buddy and send the welcome guide (TL)

## First day

- [ ] 4. Sign in to Microsoft 365 and check that Excel, SharePoint and Planner open (N)
- [ ] 5. Read the welcome guide and the document naming convention (N)
- [ ] 6. Short intro call with the team: who does what (TL)
- [ ] 7. Open the resource tracker together and walk through the three sheets: employees, projects, assignments (B)

## First week

- [ ] 8. Read the time logging policy and the overtime guidelines (N)
- [ ] 9. Refresh the tracker with Power Query on a copy and check that the totals did not change (N, with B)
- [ ] 10. Find one employee in the tracker and explain their load for one month to the buddy (N)
- [ ] 11. Fill in a resource request form for a test project (N)
- [ ] 12. Take one small task from the Planner board and move it to Done (N)

## First month

- [ ] 13. Prepare the monthly load table for one month and compare it with the pivot table (N, review by B)
- [ ] 14. Update one slide of the resource report with new figures (N, review by TL)
- [ ] 15. Feedback talk: what was unclear in the onboarding, what to change in this checklist (TL and N)

## Notes

- If access is missing, write to the team lead the same day. Do not wait until the end of the week.
- Steps 9, 13 and 14 are done on a copy of the tracker, never on the main file.
